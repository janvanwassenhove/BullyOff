# Art prompts — the generated imagery (ADR-012)

Every shipped image in `apps/manager/public/{title,intro,onboarding,portraits}/` was generated with ChatGPT (image model, 2026-08-22) from the prompts below, then fitted to the exact size the component expects with `tools/art/fit.py` (cover-crop around a focus point + Lanczos resize → webp) or `tools/art/portraits.py` (3 × 2 sheet → six 192 × 224 portraits). Nothing is traced from a real photograph, club or person; every prompt forbids text, logos, badges and recognisable faces.

Shared art direction (from the design handoff): dark ink background (`#06080a`–`#0b1014`), desaturated dark teal, one emerald accent (`#1f9a63`), cream linework (`#e9e4d8`) for the illustrated cards, floodlit and freshly watered turf for the cinematic pieces, painterly rather than photographic.

To regenerate an asset: paste the prompt, download the PNG, then

```bash
python tools/art/fit.py source.png apps/manager/public/intro/poster.webp 1440 560 --focus 0.5,0.4
```

```bash
python tools/art/portraits.py sheet.png m apps/manager/public/portraits
```

Not generated: key-moment thumbnails in the post-match report (rendered from the replay at the moment's tick), club crests (procedural, `ui/Crest.vue`), the PWA icons (`tools/icons/make-icons.cjs`). The intro film (`intro/film.mp4`) is still optional; the poster plays with a push-in until one exists.
